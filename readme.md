# Para rodar a aplicacao:

## 1- Clone o repositorio
    git clone https://github.com/RafaSobral/Crud_FastApi     

## 2- Crie uma venv
    python -m venv venv   

## 3- Inicie a venv  
   .\venv\Scripts\activate  

## 4- Instale os requisitos
   pip install -r requirements.txt
  
## 5- Rode a aplicacao
   uvicorn main:app --reload
